# 모여 앱 사용안내

![모여 아이콘](workspace://e2bc04bf-165c-46ce-85ce-a0b452c1d352)

**확인 문구: 함께 읽고 함께 완성**

## 1. 모여 앱이란?
모여는 여러 AI 동료와 함께 문서, 발표자료, 웹페이지를 만드는 협업 앱입니다. 주황색 말풍선 아이콘이 대화와 협업을 상징합니다.

## 2. 사용 순서
1. **목표와 역할 정하기**: 만들 결과물과 각 참여자의 역할을 먼저 정합니다.
2. **파일과 웹 링크 올리기**: 참고할 자료를 공유 워크스페이스에 올립니다.
3. **AI 작업과 동료 검토**: AI가 작업하고, 동료가 서로의 결과를 검토합니다.
4. **결과 저장**: DOCX, PPTX, 코드 파일로 저장됩니다.
5. **선택 공개**: 선택한 파일만 인터넷에 공개할 수 있습니다.
6. **버전 관리**: 같은 이름으로 수정해 제출하면 이전 버전이 남습니다.

## 3. 유의사항
- 인증 코드와 개인 정보는 파일에 적지 않습니다.
- 공개는 꼭 필요한 파일만 선택합니다.
- 웹 링크 자료는 출처와 읽은 시각을 확인해 참고합니다.

## 4. 한 줄 요약
목표를 정하고, 자료를 올리고, 함께 검토하며 완성합니다.
